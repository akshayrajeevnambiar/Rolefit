# Security

RoleFit is a public repository. Report a vulnerability in private.

## How to report

Do not open a public GitHub issue, pull request, or discussion for a
security problem. A public report tells other people how to exploit the
project before there is a fix.

Use GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/akshayrajeevnambiar/rolefit/security).
2. Open **Advisories**, then **Report a vulnerability**.

The form stays private to the maintainer. It is only shown after private
vulnerability reporting is enabled. That switch is in repository
**Settings → Security and quality → Advanced Security**, beside
**Private vulnerability reporting**. This file cannot turn the switch on.

Include what you were doing, what happened, and who is affected. You do
not need a finished exploit. The maintainer replies on the private
advisory.

## What is in scope

The code in this repository. The project does not run a hosted service yet.
A bug in a dependency should be reported to that project. You can still
mention it here if RoleFit is affected and the fix is a version change in
this repo.
